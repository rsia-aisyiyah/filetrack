# 📂 FileTrack

**FileTrack** adalah aplikasi **API Client** untuk platform penomoran surat otomatis yang intuitif, dirancang khusus untuk **RSIA Aisyiyah Pekajangan**.  
Aplikasi ini digunakan oleh **Bagian Sekretariat** dan **Diklat** untuk menyederhanakan proses pengelolaan surat, sehingga administrasi lebih efisien dan terstruktur.

---

## 🚀 Fitur Utama
- **🔢 Penomoran Surat Otomatis**  
  Memberikan nomor surat secara otomatis sesuai aturan yang berlaku, sehingga meminimalisir kesalahan manual.
  
- **📑 Manajemen Surat**  
  Mudah mengelola, melacak, dan mencari surat berdasarkan kategori atau periode tertentu.

- **🔐 Autentikasi & Autorisasi Aman**  
  Menggunakan **JWT (JSON Web Token)** yang diimplementasikan pada **Laravel Backend** untuk memastikan keamanan akses.

- **⚡ Integrasi Internal**  
  Terhubung langsung dengan sistem backend RSIA untuk sinkronisasi data surat.

---

## 🛠️ Teknologi yang Digunakan
- **Frontend**: [Vue.js](https://vuejs.org/) dengan [Nuxt](https://nuxt.com/)  
- **UI Framework**: [Nuxt UI](https://ui.nuxt.com/)  
- **Backend**: [Laravel](https://laravel.com/) dengan dukungan **JWT Authentication**  
- **Database**: MySQL  

---

## 📌 Catatan
Aplikasi ini **hanya digunakan untuk internal RSIA Aisyiyah Pekajangan** dan tidak ditujukan untuk distribusi publik.
